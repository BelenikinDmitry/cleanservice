# Subagent'ы проекта

Здесь можно определить кастомных subagent'ов, специфичных для этого проекта.

## Как добавить агента

Создай файл `<имя-агента>.md` с frontmatter:

```markdown
---
name: my-agent
description: Когда использовать этого агента.
tools: Read, Grep, Bash   # опционально: ограничить набор инструментов
model: sonnet             # опционально
---

Системный промпт агента: роль, задачи, ограничения.
```

Если каталог не нужен — можно удалить.
