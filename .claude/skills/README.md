# Skills проекта

Здесь живут кастомные skills для Claude Code, специфичные для этого проекта.

## Как добавить skill

Создай подпапку с именем skill'а, внутри — файл `SKILL.md`:

```
.claude/skills/
  my-skill/
    SKILL.md
    references/   (опционально: доп. файлы, шаблоны, скрипты)
```

`SKILL.md` начинается с frontmatter:

```markdown
---
name: my-skill
description: Когда и для чего использовать этот skill (это читает модель, чтобы решить, применять ли skill).
---

Инструкции, которые Claude выполнит при вызове skill.
```

Skill вызывается пользователем как `/my-skill` или автоматически,
когда его описание совпадает с задачей.
