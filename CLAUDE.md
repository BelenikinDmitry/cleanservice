# CLAUDE.md

Этот файл — контекст для Claude Code при работе с репозиторием `cleanservice`.
Заполни разделы ниже по мере развития проекта; лишнее — удаляй.

## О проекте

Рабочее пространство для подготовки и ведения рекламных кампаний в Яндекс.Директ
для клининговой компании. Каждое направление клининга — отдельный подкаталог
в `yadirect/`: объявления, ключевые фразы, минус-слова, посадочные страницы
и прочие материалы кампании по этому направлению.

## Площадка

- Яндекс.Директ

## Структура каталогов

- `yadirect/` — рекламные кампании Яндекс.Директ
  - `yadirect/okna/` — направление «Мытьё окон»
  - `yadirect/<направление>/` — по мере добавления новых направлений клининга
- `.claude/skills/` — кастомные skills для Claude Code
- `.claude/agents/` — кастомные subagent'ы для Claude Code

## Кампания "Мытье окон"
Рабочий каталог cleanservice/yadirect/okna
В объявлениях нужно оразить услуги по мытью окон в коттеджах, загородных домах, мытье окон и лоджий в квартирах. 
И делаем упор на мытье окон в коттеджных посёлках. 

## Конвенции

### Ограничения символов в объявлениях Яндекс.Директ

Единые для всего проекта — действуют во всех подкаталогах `yadirect/<направление>/`.

| Элемент | Лимит |
|---|---|
| Заголовок | 56 знаков (включая пробелы и знаки препинания); одно слово — не более 22 символов |
| Дополнительный заголовок | 30 знаков и 15 знаков препинания; одно слово — не более 22 знаков |
| Текст объявления | 81 знак и 15 знаков препинания; одно слово — не более 23 знаков (текст может обрезаться в зависимости от места показа) |
| Ссылка | 1024 знака (включая протокол) |
| Отображаемая ссылка | 20 знаков (не считая домен) |
| Уточнения | 25 знаков с учётом пробелов; суммарная длина уточнений на объявление — не более 132 знаков на десктопах и не более 76 на мобильных |
| Быстрая ссылка — заголовок | 30 знаков |
| Быстрая ссылка — описание | не более 60 знаков |
